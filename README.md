# Körfuboltaáskorun

Einfaldur umbunarleikur fyrir nemendur. Leikurinn virkar með lyklaborði, mús og snertiskjá.

## Stjórnun

- **← / →** eða **A / D**: færa leikmann.
- **W / S** eða **↑ / ↓**: hækka eða lækka skotlínuna.
- Smella á völlinn: færa leikmann á valinn stað.
- Halda inni **bilslá**, **Enter** eða **SKJÓTA**: safna krafti.
- Sleppa takkanum: skjóta.

## Leikstillingar

- **10 bolta áskorun:** Fáðu sem flest stig með tíu boltum.
- **Áskorun:** Stattu í rauða hringnum og skjóttu. Hringurinn færist eftir hvert skot.
- **Frjáls æfing:** Ótakmarkaðir boltar án tímamarka.

Leikurinn geymir met í tækinu, er PWA-vænn og getur virkað án nettengingar eftir fyrstu opnun.
